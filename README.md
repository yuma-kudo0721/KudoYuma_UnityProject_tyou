# はらぺこ蝶の大脱出劇（札幌ゲームキャンプ）

## 概要
本作は、蝶を操作しながら食べ物を集め、  
角ばる／丸くなるといった形状変化を経て、  
最終的に壁へ突進し破壊する爽快感を味わうアクションゲームです。

初対面のメンバーが集まり2日間でゲームを制作するイベント  
「札幌ゲームキャンプ」にて、  
テーマ「かくちょう（拡張）」をもとに制作しました。

## 遊び方
1. スペースキーでゲーム開始  
2. 蝶を左右に操作して食べ物を取得  
3. 角ばった食べ物を取ることで蝶の形状が変化  
4. 成長した蝶が壁に突進し、破壊します

## プログラム面でのこだわり
### 成長状態を「数値ではなく見た目」で伝える設計
プレイヤーの成長状態を数値UIで表示するのではなく、  
モデル自体が段階的に変化する仕組みを実装しました。

成長段階は変数で管理し、その値に応じて表示モデルを切り替えることで、  
現在の状態を直感的に把握できるようにしています。

また、短期間開発でも安定して動作させるため、  
`Mathf.Min / Mathf.Max` を用いて配列の範囲外アクセスを防止し、  
バグを未然に防ぐ安全な実装を意識しました。
